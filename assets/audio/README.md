# Локальные аудиофайлы «Переулка»

В этой папке пока нет MP3 и фоновых дорожек. Плеер работает без них; отсутствующая согласованная запись отмечается в интерфейсе. Отключённые звуковые слоты с `src: null` не создают сетевых запросов.

## Утверждённая запись панорамы бара

Создателю нужно отдельно добавить файл с точным именем:

```text
assets/audio/Pereulok_voice_natural_v2.mp3
```

Это согласованная бережно обработанная версия второго детективного дубля. Сохраните естественную подачу, исходную запинку и паузы. Плеер не синтезирует голос, не ускоряет запись и не применяет к ней повторное шумоподавление или компрессию.

Путь уже настроен в `scenes.js`. Достаточно добавить файл и перезагрузить страницу; менять код плеера не нужно. Запускайте проект через локальный HTTP-сервер:

```sh
python3 -m http.server 8000
```

Затем откройте http://localhost:8000 и нажмите **Начать**. Аудио не стартует автоматически при загрузке страницы или в режиме **Комикс**. Страница, открытая как `file://`, предназначена для просмотра без аудио; загрузку MP3 проверяйте через HTTP.

Сцена панорамы включает 2 секунды до голоса, всю фактическую длительность MP3 и 1,5 секунды после записи. Если файла нет либо загрузка не удалась, используется резерв 35 секунд без голоса с понятным сообщением. Ориентир записи около 31 секунды не служит пределом и не обрезает более длинную запись.

Файл остаётся у автора до отдельного добавления. Не нужно скачивать sandbox-ссылку ChatGPT или искать замену голосу.

## Атмосфера, музыка и эффекты

Подготовленные слоты в `window.AlleyStory.audio.beds`:

| Слот | Материал | Текущее состояние |
| --- | --- | --- |
| `rain` | Дождь и уличная атмосфера | `src: null` |
| `room` | Приглушённые разговоры в баре | `src: null` |
| `jazz` | Тихий джаз | `src: null` |
| `dishes` | Посуда | `src: null` |

Процедурных демонстрационных шумов нет. Отключённые слоты не имитируют готовую звуковую сцену. Живого голоса Даши пока тоже нет.

Когда подходящие материалы будут готовы, добавьте собственные или разрешённые лицензией файлы в эту папку, а их относительные пути укажите в `src` соответствующих слотов `scenes.js`. До этого оставьте `null`, без фиктивных URL. У отдельных эффектов задаются `src`, время `at` в миллисекундах и `gain`; значение `src: null` оставляет эффект выключенным.

Общие уровни находятся в `audio.volumes` для каналов `voice`, `ambience`, `music`, `effects`. Параметр `audio.crossfade` по умолчанию равен 2000 мс. `audio.duck` содержит коэффициенты приглушения фоновых каналов и времена `attack`/`release`; он помогает сохранять разборчивость голоса без обработки самого MP3. Уровни фоновых дорожек для каждой сцены задаются в её `audio.beds`.

После добавления материалов проверьте переходы дождь → бар → дождь, отсутствие одновременного проигрывания дублирующихся дорожек и остановку всех активных источников при паузе, навигации, смене режима, уходе со вкладки и завершении истории.

## Проверки

Из корня проекта можно запустить:

```sh
node --test tests/player.test.cjs tests/audio-engine.test.cjs
```

Эта инструкция не заменяет результаты прогона. Отдельно прослушайте согласованную запись целиком через HTTP-сервер, особенно её последние слова, паузу/продолжение и переход в следующую сцену.
